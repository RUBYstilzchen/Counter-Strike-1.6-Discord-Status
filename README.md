# Discord Bot for Counter-Strike 1.6 Server Status

Простий та ефективний Discord-бот, який відстежує стан сервера **Counter-Strike 1.6** у реальному часі та відображає поточний онлайн і мапу в ігровому статусі (Presence). 

## 📋 Опис роботи
Бот періодично (кожні 30 секунд за замовчуванням) опитує CS 1.6 сервер за допомогою бібліотеки `GameDig`. 
* **Фільтрація ботів:** Бот автоматично відсікає HLTV та фейкових гравців (ботів), показуючи в Discord лише **реальний онлайн**.
* **Відмовостійкість:** Якщо сервер не відповів один чи два рази, бот утримує останній відомий статус. Якщо сервер недоступний 3 рази поспіль (понад 1.5 хвилини), статус змінюється на «Сервер офлайн ❌».

> 💡 **Про архітектуру та безпеку:**
> Токен Discord-бота та налаштування прописані безпосередньо у коді. Це зроблено свідомо: бот розрахований на запуск **безпосередньо на тій самій машині (VDS/Dedicated), де працює ігровий сервер**. Оскільки доступ до сервера вже є ізольованим та приватним, винесення конфігурації в окремі файли є надлишковим.

## 🛠 Встановлення залежностей

Перед запуском переконайся, що на сервері встановлено **Node.js** (рекомендовано v16+).

```bash
# Ініціалізація проєкту (якщо потрібно)
npm init -y
```

# Встановлення необхідних модулів
```bash
npm install discord.js gamedig
```

Керування за допомогою Systemd (systemctl)
Щоб бот працював у фоні 24/7 та автоматично піднімався після перезавантаження сервера, налаштуємо службу systemd.

1. Створення сервісу
Створи файлик конфігурації (заміни юзер та /шлях/до/бота на свої дані):
```bash
sudo nano /etc/systemd/system/cs-discord-bot.service
```
Встав туди наступний текст (заміни бузер та шлях/до/бота на свої дані):
```bash
[Unit]
Description=CS 1.6 Discord Status Bot
After=network.target

[Service]
Type=simple
User=юзер
WorkingDirectory=/шлях/до/бота
ExecStart=/usr/bin/node index.js
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```
2. Команди для керування сервісом
```bash
# Оновити конфігурацію systemd після створення файлу
sudo systemctl daemon-reload

# Увімкнути автозапуск бота разом із сервером
sudo systemctl enable cs-discord-bot

# Запустити бота
sudo systemctl start cs-discord-bot

# Зупинити бота
sudo systemctl stop cs-discord-bot

# Перезапустити бота
sudo systemctl restart cs-discord-bot

# Перевірити статус роботи та останні логи
sudo systemctl status cs-discord-bot
```
