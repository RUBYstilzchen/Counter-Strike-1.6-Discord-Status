# Discord Bot for Counter-Strike 1.6 Server Status

Простий та ефективний Discord-бот, який відстежує стан сервера **Counter-Strike 1.6** у реальному часі, відображає поточний онлайн і мапу в ігровому статусі, а також надсилає сповіщення в приватні повідомлення у разі падіння сервера.

---

## Особливості та логіка роботи

* **Фільтрація ботів:** Бот автоматично відсікає HLTV та фейкових гравців (ботів), показуючи в Discord лише **реальну кількість гравців**.
* **Відмовостійкість:** Якщо сервер не відповів один чи два рази, бот утримує останній відомий статус. Статус змінюється на «Сервер офлайн ❌» лише після 3 невдалих спроб поспіль.
* **Сповіщення в приват (DM):** У разі падіння сервера бот миттєво надішле вам повідомлення в приватні повідомлення Discord. Бот напише лише **один раз** при падінні та **один раз** при відновленні роботи сервера.
* **Безпека (.env):** Усі конфіденційні дані (токени, ID, IP сервера) повністю ізольовані в окремому файлі конфігурації.

## Встановлення та запуск
* **1. Системні вимоги**
Переконайтесь, що на сервері/ПК встановлено Node.js (рекомендовано v18+).

* **2. Клонування та встановлення залежностей**
Завантажте файли проєкту у зручну директорію, відкрийте у ній термінал та виконайте команду для автоматичного встановлення всіх модулів:

```
npm install
```

* **3. Налаштування конфігурації**
У файлі .env змініть дані на свої

## Керування за допомогою Systemd
Щоб бот працював у фоні 24/7 та автоматично запускався після перезавантаження системи, налаштуємо службу systemd.

* **1. Створення сервісу**
Створіть файл конфігурації служби:

```
sudo nano /etc/systemd/system/cs-discord-bot.service
```
Вставте туди наступний текст, замінивши юзер та /шлях/до/бота на власні коректні дані:

```
[Unit]
Description=CS 1.6 Discord Status Bot
After=network.target

[Service]
Type=simple
User=юзер
WorkingDirectory=/шлях/до/бота
ExecStart=/usr/bin/node index.js
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

* **2. Оновити конфігурацію systemd після створення файлу**
```
sudo systemctl daemon-reload
```

# Команди для керування сервісом

* **Увімкнути автозапуск бота разом із системою**
```
sudo systemctl enable cs-discord-bot
```

* **Запустити бота**
```
sudo systemctl start cs-discord-bot
```

* **Перевірити статус роботи та останні логи**
```
sudo systemctl status cs-discord-bot
```

* **Перезапустити бота (наприклад, після змін у файлі .env)**
```
sudo systemctl restart cs-discord-bot
```

* **Зупинити бота**
```
sudo systemctl stop cs-discord-bot
```
